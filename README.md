# 제품 사진 한 장에서 AI 광고와 SF 코미디까지

Comfy Cloud 실습용 워크플로, 기준 이미지, 장면별 프롬프트와 앵커 립싱크 예제입니다.

[실습 ZIP 다운로드](https://github.com/dante01yoon/comfy-product-film-tutorial/releases/download/v3/comfy-family-practice-v3.zip)

ZIP을 풀고 README.ko.md부터 읽어주세요. Comfy Cloud에서 JSON을 불러온 뒤 제공된 이미지와 오디오를 업로드하고 각 입력 노드에서 다시 선택합니다. 실행 전 화면에 표시되는 크레딧을 확인하세요. 생성 서비스 사용에는 비용이 발생하며 결과는 실행마다 달라질 수 있습니다.

제품 광고 3컷, 영화 장면 3개, 앵커 립싱크 1개 워크플로를 포함합니다. 영화는 각 장면을 생성한 뒤 별도 편집으로 완성했습니다. 영상 속 뉴스, 인물, 브랜드와 사건은 가상의 SF 코미디입니다.
